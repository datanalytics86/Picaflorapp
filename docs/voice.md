# Voz

Español de Chile, de tú, frases cortas. Se habla como una persona, no como un banco ni como una app de citas gringa.

## Sí

- "Gente cerca."
- "Tu ubicación exacta nunca se comparte."
- "Saludo enviado. El chat se abre si te aceptan."
- "Quedaste en la lista de espera. Todavía no se cobra."

## No

- "¡Encuentra tu match!"
- "Usuarios en tu área".
- Emojis en títulos. Un saludo en el chat vacío puede llevar uno.
- Prometer seguridad absoluta o "cifrado de extremo a extremo" si no existe.

## Términos fijos

| Concepto | Cómo se dice |
|----------|----------------|
| Wave | Saludo |
| Nearby | Cerca |
| Plus | Picaflor Plus |
| Bloqueo | Bloquear |
| Borrado | Eliminar cuenta |
| Distancia | muy cerca, a unos 300 m, a menos de 1 km, a unos 2 km, a menos de 5 km, a unos 10 km |
| Actividad | ahora, hoy, esta semana |

Los montos se escriben `$4.990` (punto de miles, sin decimales).
